🏃‍♂️ Shadow Sprint Run 2026

দৌড় হোক নিজের গতিতে, নিজের জায়গা থেকে—কিন্তু লক্ষ্য হোক একটাই: নিজেকে ছাড়িয়ে যাওয়া!

RavenX Bangladesh নিয়ে এসেছে Shadow Sprint Run 2026—একটি সম্পূর্ণ Virtual Running Challenge, যেখানে আপনি দেশের যেকোনো প্রান্ত থেকে, আপনার সুবিধামতো সময়ে অংশগ্রহণ করতে পারবেন। কোনো নির্দিষ্ট মাঠে বা নির্দিষ্ট সময়ে উপস্থিত থাকার প্রয়োজন নেই। শুধু আপনার দৌড়, আপনার পরিশ্রম এবং আপনার অর্জন—সবকিছুই হবে আপনার নিজের মতো করে.

Virtual Run কী?

Virtual Run হলো এমন একটি Running Event যেখানে অংশগ্রহণকারীরা নির্দিষ্ট কোনো venue-তে একসাথে দৌড়ান না। বরং Event Period-এর মধ্যে নিজের সুবিধামতো যেকোনো জায়গায় এবং যেকোনো সময়ে নির্ধারিত দূরত্ব সম্পন্ন করতে পারেন। আপনি চাইলে বাসার আশেপাশের রাস্তা, পার্ক, মাঠ, ট্র্যাক কিংবা আপনার পছন্দের যেকোনো নিরাপদ জায়গায় দৌড়াতে পারেন।

আপনার দৌড় Strava App-এর মাধ্যমে Record করতে হবে। দৌড় শেষ করার পর Strava-এর Run Activity Link আমাদের নির্ধারিত Submission Form-এর মাধ্যমে জমা দিতে হবে।

অর্থাৎ—আপনার Run, আপনার সময়, আপনার পথ; কিন্তু Challenge আমাদের সবার। 🖤

EVENT PERIOD

01 October – 31 October 2026

এই এক মাসের মধ্যে আপনার সুবিধামতো যেকোনো দিনে আপনার নির্বাচিত Distance সম্পন্ন করতে পারবেন।

Location: Virtual — Run Anywhere, Anytime

Registration Opens: 10 May 2026

RUN CATEGORIES

  • 3.1 KM — Silver
  • 6.66 KM — Golden
  • 13 KM — Black

আপনার সক্ষমতা ও প্রস্তুতি অনুযায়ী যেকোনো একটি Category নির্বাচন করে Challenge সম্পন্ন করুন।

কীভাবে অংশগ্রহণ করবেন?

১️ Registration করুন

নির্ধারিত সময়ের মধ্যে আপনার পছন্দের Run Category নির্বাচন করে Registration সম্পন্ন করুন।

২️ E-BIB সংগ্রহ করুন

Event-এর আগে আপনার Official E-BIB Number ই-মেইলের মাধ্যমে পাঠিয়ে দেওয়া হবে।

৩️ আপনার Run সম্পন্ন করুন

01 October – 31 October 2026-এর মধ্যে আপনার সুবিধামতো যেকোনো দিন ও সময়ে নির্বাচিত Distance সম্পন্ন করুন।

৪️ Strava দিয়ে Run Record করুন

আপনার পুরো Run অবশ্যই Strava App ব্যবহার করে Record করতে হবে, যাতে Distance, Time এবং অন্যান্য Run Data সংরক্ষিত থাকে।

৫️ Run Submission করুন

Run শেষ করার পর আপনার Strava Activity Link এবং প্রয়োজনীয় তথ্য Official Submission Form-এর মাধ্যমে জমা দিন। Submission Form-এর Link আপনার ই-মেইলে পাঠিয়ে দেওয়া হবে।

৬️ Verification শেষে Finisher হোন!

আপনার Run সফলভাবে সম্পন্ন ও যাচাই হওয়ার পর আপনি পাবেন আপনার Finisher Rewards।

FINISHERS-দের জন্য থাকছে

  • Exclusive China Finisher Medal
  • Surprise Gift
  • Personalized E-Certificate
  • Official E-BIB Number

অর্থাৎ, শুধু দৌড় নয়—আপনার এই অর্জনকে স্মরণীয় করে রাখার জন্য থাকছে বিশেষ Finisher Recognition।

দৌড়ের সময় আপনার ছবি তুলুন, আপনার Running Journey শেয়ার করুন এবং আমাদের Community-এর সাথে যুক্ত থাকুন।
